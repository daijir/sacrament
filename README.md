# 聖餐会（Sacrament Meeting）お話・お祈り 推薦＆スケジューラー CLI

末日聖徒イエス・キリスト教会のワード・支部における、聖餐会のお話（Talk）やお祈り（Prayer）の割り当て業務を支援するローカルCLIツールです。

「人間（ビショップリック）が祈りを通して霊感で選定する」プロセスを尊重しつつ、複雑な制約（インターバル、夫婦・家庭の事情、男女比、青少年の育成）を満たす**推薦候補の絞り込みとスケジュール作成**をアシストします。

---

## 💡 特徴と設計思想

1. **100% ローカル完結（プライバシー保護）**
   - 外部クラウドへの送信は一切行いません。教会のデータ保護規約（*General Handbook* 38.8.31）に完全準拠し、個人のPC内のみで動作します。
2. **「自動決定」ではなく「推薦（レコメンド）」**
   - アルゴリズムが勝手に人を決定するのではなく、「なぜこの人が候補なのか（経過日数、夫婦希望など）」の理由付きで上位候補を提示します。
3. **現場のリアルな制約に対応**
   - 第1日曜日（断食証しの会）の自動判別（お話枠なし）
   - 夫婦での同日登壇希望
   - 乳幼児がいる家庭の同日重複回避
   - 開会・閉会の祈りの男女バランス
   - 新会員への配慮（お祈りや短めのお話の優先）
   - ビショップリック（司会・進行）の除外
4. **断られた時の「即座の差し替え」**
   - 会員に打診して都合が悪かった場合、ワンコマンドで次点候補（Rank 2〜5）を即座に再提示。

## 🚀 使い方

Python 3 がインストールされていれば、追加ライブラリのインストール（pip install）なしで動作します。

### 1. 初回セットアップ（ダミー履歴の生成）
架空の過去登壇・祈祷実績ログ（history.json）を初期生成します。
`ash
python sacrament.py init
`

### 2. 会員のお話ご無沙汰ランキング (status)
誰が長い間お話をしていないか（公平性のチェック）を一覧表示します。
`ash
python sacrament.py status
# 上位30件表示したい場合:
python sacrament.py status --top 30
`

### 3. 特定の日曜日の候補者をレコメンド (ecommend)
ビショップリック会議で祈りつつ検討するための候補者リストを表示します。
`ash
python sacrament.py recommend 2026-10-11
`
* **青少年枠（5分）**: インターバルが空いているユース上位3名
* **成人枠（10-12分）**: 夫婦ペア候補 ＋ 単独候補上位5名
* **お祈り枠**: 開会・閉会の男女ペア候補

### 4. 断られたときの差し替え (eplace)
打診した会員に断られた際、その人を除外した次点候補を表示します。
`ash
python sacrament.py replace 2026-10-11 --role adult_talk --exclude  加藤 秀樹
`

### 5. スケジュールの一括ドラフト作成 (plan)
向こう数週間〜四半期の全体バランスをシミュレーションします。
`ash
# 今後12週分のドラフトを作成
python sacrament.py plan --weeks 12

# 開始日を指定する場合
python sacrament.py plan --start 2026-10-04 --weeks 8
`

## 📊 会員データ（members.csv）の仕様

Excelやテキストエディタで直接メンテナンスできます。

| カラム名 | 型 | 説明 |
| :--- | :--- | :--- |
| id | 数値 | 会員ID（一意の番号） |
| 
ame | 文字列 | 氏名 |
| gender | M / F | 性別（男性: M, 女性: F） |
| category | adult / youth | 区分（成人: adult, 青少年: youth） |
| household_id | 数値 | 世帯ID（同じ家族・夫婦は同じ番号） |
| is_bishopric | True / False | ビショップリックフラグ（Trueなら通常枠から除外） |
| couple_talk_together | True / False | 夫婦登壇希望（Trueなら同じ週へのペアリング優先） |
| has_small_children | True / False | 乳幼児あり（Trueなら夫婦が同日に重なるのを回避） |
| is_new_member | True / False | 新会員（Trueならお祈り優先ボーナス） |
